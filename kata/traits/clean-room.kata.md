# .clean-room

```
/* Trait — perishable independence. Compose onto a reviewing seat. */

.clean-room {
  enters-with:
    current-topic,
    attachments,
    source-of-truth-documents;

  denies:
    debate-history-intake,
    prior-round-narratives,
    standing-meeting-attendance;

  must:
    review-artifact-not-narrative,
    recommend-blinded-check-for-public-contracts,
    exit-when-question-answered;
}

/* Independence is perishable — guard it by staying out of the room. */
```
